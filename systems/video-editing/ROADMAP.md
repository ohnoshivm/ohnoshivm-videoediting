# Roadmap

This is a direction, not a promise of delivered features.

- **Prove the line:** finish the first approved reel with corrected captions and human listening; measure active time and document gaps. Prove Real SFX on cleared recordings and verify Earshot's models locally before claiming semantic audio analysis works.
- **Improve quality:** add cue-sheet support, stronger visual inserts, varied video framing and audio stem handling to an isolated template; test with real briefs and human feedback. Preserve existing projects and source footage.
- **Make it reusable:** define small stable contracts for edit decisions, captions, cue times, sound-source records, output presets and machine-readable QA. Build adapters for the actual renderer/editor in use.
- **Protect provenance:** keep third-party upstreams pinned with notices, model licences and per-asset credits; use explicit public/private boundaries and prevent media, models and secrets entering public Git.
- **Measure scale:** benchmark 8 GB memory pressure, render time and failure recovery before promising weekly capacity. Record versions and changes; use separate maker and checker before release.
- **Future integrations:** consider NLE handoff, an approved B-roll library, reusable sound kits, selective model evaluation and CI tests only after each is justified and licensed. No new paid service or download by default.
